## 系統簡介

本系統是一個專為 FPS 遊戲玩家、電競賽事觀眾與虛擬飾品投資者打造的綜合情報平台。
為了解決玩家過往需要在多個不同平台之間切換，才能同時獲得最新賽事戰績與飾品市場價格走勢的「資訊破碎」問題，本專案將這兩大核心需求整合在一起。
系統具體功能包含：
1. **職業戰隊與選手戰績查詢**：快速掌握隊伍近況與賽事走勢。
2. **虛擬飾品市場價格圖表與排行**：觀看各項飾品歷史走勢與漲跌幅，尋找潛在投資標的。
3. **個人投資組合追蹤**：記錄個人持有飾品的買入價與數量，追蹤當前市值與損益狀況。
4. **飾品到價提醒功能**：指定目標價位通知，精準把握買賣時機。
5. **社群討論與賽事預測**：提供玩家交流心得與預測比賽結果的互動空間。
